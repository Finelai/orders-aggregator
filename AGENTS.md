# Инструкции для работы с проектом

## Контекст

- Сервис на TypeScript и Fastify работает с PostgreSQL и внешним API заказов. Описание API и структуры находится в `README.md`.
- Если работа относится к тестовому заданию, сначала прочитайте `TASK.md` и учитывайте его условия.
- Деньги внутри сервиса представлены целыми копейками; на входе внешнего API и в ответах используются рубли. Время хранится в UTC. Ошибки бизнес-логики наследуются от `AppError`.

## Изменения и проверки

- Сохраняйте строгие настройки TypeScript. Не отключайте проверки, чтобы обойти ошибки; исправляйте причину.
- Для форматирования используйте Biome: `npm run format`. Команда меняет файлы.
- После изменений запускайте подходящие проверки: `npm run lint`, `npm run format:check` и `npm run typecheck`.
- Запускайте `npm test` для изменений поведения. Интеграционным тестам нужна тестовая база PostgreSQL; не используйте базу с нужными данными.
- Изолированный стенд находится вне репозитория приложения, в соседней папке `../isolated-stand`. При его наличии `sh ../isolated-stand/build.sh` запускает проверки Biome и тесты с отдельной временной базой, затем собирает образы. Подробнее — в `../isolated-stand/README.md`.
- Добавляйте или обновляйте тесты для новой функциональности и исправлений, если это предусмотрено задачей.
